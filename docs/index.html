怎么判，什么不算

Chrome 打开 Google Maps 卫星（Airbus / CNES / Maxar，版权 2026），对照 OSM 地名和 2026-08 公开报道。卫星可能滞后于地面进度——圣家营已是实例：Google 图层仍是农田，其他高分源（Esri 等）同坐标已出楼。

分布规律

  • 三处确认 / 候选点落在同一东西向条带：北纬 40.98°–41.04°、东经 113.24°–113.33°，G6 以北、G335 以南，紧贴 G110 两侧，距城区 11–17 公里
  • 条带西端益武堂最成熟，向东到四号村是施工最密集的一段，圣家营把集聚区向北顶出一翼
  • 城区及以西、黄旗海方向 50 公里圈内未见机房形态；前旗是唯一的南向离群点

算作在建机房

  • 超大无内院矩形、模块化并排
  • 屋顶冷机、裸露楼板、塔吊、矩形垫层
  • 与苹果大道 / 阿里大道 / 益武堂或 OSM 机房名交叉

明确排除

  • 白家湾炼丰石化（储罐、排烟）
  • 土贵乌东传统工业园
  • 圣家营附近农业大棚
  • 城区 552 m 原点的住宅工地

还需要现场做的

  • 用高新区规划图把 PLATE A03–A07 和业主对上
  • 钉死圣家营北大院业主：规划图或工地牌匾（万润？快手星河？其他运营商？）
  • 前旗京蒙零碳园需要单独坐标，不要用土贵乌工业园顶替
