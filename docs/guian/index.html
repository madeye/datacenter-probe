怎么判，什么不算

Esri World Imagery 对照 OSM 具名要素。腾讯是洞库，判据改成山体 + 洞外方仓，不能要求看见常规大厅。

算作机房

  • 超大无内院矩形、屋顶冷机
  • OSM telecom=data_center 或品牌名
  • 洞库：layer=-1 的山体 + 洞外大厅

明确排除

  • 机场跑道
  • 住宅和学校操场
  • 富士康地面厂房本身
