怎么判，什么不算

阳泉不像乌兰察布或贵安那样铺开。50 km 圈里能指认的机房就这一块。

算作机房

  • 并排灰顶大矩形
  • 屋顶机电密布的方楼
  • OSM telecom=data_center

明确排除

  • 采坑
  • 蓝顶厂房、铁路南侧普通厂房
  • 环形广场办公（云谷）不要单独当机房
