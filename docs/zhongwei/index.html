中卫周边数据中心建设情况

中卫的机房不在沙坡头城区，而在北面戈壁上的西部云基地。Esri 图上是一条东西向、光伏夹着的园区：六栋白顶大厅并排是主体，紧邻东侧两栋带屋顶机电，再往东一栋，西侧在建，路南另有一组；东端还有整平垫层空着。OSM 把整条带写成 AWS，实际上美利云和三大运营商也在同一个园。

怎么判，什么不算

圆心不在中卫城区，在城北戈壁。南侧化工厂容易被 OSM 工业用地带进来，必须看储罐。

算作机房

  • 戈壁上超大白顶无内院矩形、模块化并排
  • 旁边光伏可以当配套，本身不是机房

明确排除

  • 储罐、管廊、排烟
  • 城区政府办公楼（云计算大数据发展局）
